# Amazon Web Services (AWS) Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers a large collection of cloud services for computing, storage, databases, networking, security, analytics, and application development. AWS allows organizations to use IT resources over the internet without having to purchase and maintain all of the physical infrastructure themselves.

AWS is widely used by startups, educational institutions, government organizations, and large enterprises.

## 2. Global Infrastructure

AWS has a global infrastructure made up of geographic Regions and Availability Zones. AWS currently operates 39 geographic Regions and 124 Availability Zones. Each Region contains multiple isolated Availability Zones that are connected using high-bandwidth and low-latency networks.

This infrastructure allows organizations to deploy applications closer to their users, improve availability, and design systems that can continue operating even if an Availability Zone experiences a failure.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create resources, configure services, monitor applications, manage users, check service usage, and view billing information.

The console also allows users to select different AWS Regions when creating and managing regional resources.

## 4. Four Core Services

### Amazon EC2
Amazon Elastic Compute Cloud (EC2) provides virtual servers that organizations can use to run applications and workloads in the cloud.

### Amazon S3
Amazon Simple Storage Service (S3) provides scalable object storage for files, documents, images, backups, and other data.

### Amazon RDS
Amazon Relational Database Service (RDS) is a managed database service that supports relational database engines and reduces the amount of database administration required.

### AWS Lambda
AWS Lambda is a serverless computing service that allows developers to run code without managing servers. Applications can execute functions in response to events.

## 5. Three Advantages

1. **Scalability** – AWS allows organizations to increase or decrease computing resources based on demand.

2. **Global Availability** – AWS has Regions and Availability Zones around the world, allowing applications to be deployed closer to customers.

3. **Wide Range of Services** – AWS provides services for computing, storage, databases, networking, security, analytics, artificial intelligence, and many other technologies.

## 6. Typical Enterprise Use Cases

AWS is commonly used by enterprises for:

- Hosting websites and web applications
- Data backup and disaster recovery
- Database hosting
- Software development and testing
- Big data and analytics
- Artificial intelligence and machine learning
- E-commerce applications
- Enterprise application migration
