# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services for computing, storage, databases, networking, artificial intelligence, analytics, security, and application development.

Azure enables organizations to build, deploy, and manage applications using Microsoft's global cloud infrastructure.

## 2. Global Infrastructure

Microsoft Azure has a large global infrastructure consisting of more than 80 Azure regions and more than 500 datacenters. Azure regions are distributed around the world to support low latency, data residency, availability, and regulatory requirements.

Organizations can select Azure regions based on the location of their users, performance requirements, and data governance requirements.

## 3. Cloud Management Console

The Microsoft Azure management console is called the **Azure portal**. It is a web-based unified console used to create, manage, monitor, and configure Azure resources.

Through the Azure portal, users can create virtual machines, databases, web applications, storage resources, and other cloud services. Users can also monitor resources, configure dashboards, manage subscriptions, and review costs.

## 4. Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provides scalable virtual machines that allow organizations to run Windows or Linux applications in the cloud.

### Azure Blob Storage

Azure Blob Storage is Microsoft's object storage service for storing large amounts of unstructured data such as documents, images, videos, backups, and application data.

### Azure SQL Database

Azure SQL Database is a managed relational database service based on Microsoft SQL Server technology. Microsoft manages many database administration tasks so organizations can focus on their applications and data.

### Azure Virtual Network

Azure Virtual Network allows organizations to create private networks in Azure. It provides networking capabilities for connecting virtual machines and other Azure resources securely.

## 5. Three Advantages

1. **Microsoft Integration** – Azure works closely with Microsoft technologies such as Windows Server, Microsoft SQL Server, Microsoft Entra ID, and Microsoft 365.

2. **Global Infrastructure** – Azure provides a large worldwide infrastructure with many regions and datacenters.

3. **Enterprise Security and Compliance** – Azure provides security, identity, governance, and compliance capabilities designed for enterprise environments.

## 6. Typical Enterprise Use Cases

Azure is commonly used by enterprises for:

- Hosting business applications
- Windows and .NET application hosting
- Database management
- Cloud migration
- Backup and disaster recovery
- Artificial intelligence and machine learning
- Data analytics
- Hybrid cloud environments
- Enterprise networking
