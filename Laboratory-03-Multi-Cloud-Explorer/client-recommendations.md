# Cloud Platform Recommendations

## Client A – Startup Company

### Recommended Cloud Platform: AWS

AWS is a good choice for the startup because it offers a wide range of cloud services and flexible pricing options. The startup can begin with a small amount of cloud resources and increase them as the mobile application gains more users. AWS also provides services that can help the company develop, store, and deploy its application. This makes AWS a suitable platform for a startup with a limited budget and expectations of rapid growth.

### Services:
- Amazon EC2 – Compute
- Amazon S3 – Storage
- Amazon RDS – Database
- AWS Lambda – Serverless computing

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is the best choice for the university because it integrates closely with existing Microsoft technologies. The university can connect its existing Windows Server and Active Directory environment to Azure, making the migration easier to manage. Azure also works well with Microsoft 365 and other Microsoft services that the university already uses. This can reduce compatibility problems and make the transition to the cloud smoother.

### Services:
- Azure Virtual Machines – Run Windows Server workloads
- Microsoft Entra ID – Identity and access management
- Azure Blob Storage – Cloud storage
- Azure Virtual Network – Network connectivity

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform

Google Cloud Platform is a strong choice for the AI research company because it provides powerful tools for artificial intelligence and machine learning. Google Cloud offers high-performance computing resources that can be used to train and run complex AI models. Its AI and data services can also help researchers develop, test, and deploy machine learning applications. This makes GCP suitable for a company that focuses heavily on AI and requires high-performance computing.

### Services:
- Google Compute Engine – High-performance virtual machines
- Vertex AI – AI and machine learning development
- Google Kubernetes Engine (GKE) – Container and Kubernetes management
- Cloud Storage – Storage for datasets and models

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: AWS

AWS is a suitable choice for the global e-commerce company because it provides highly available and scalable infrastructure. The company can use AWS services to automatically increase or decrease resources depending on the number of customers visiting the website. AWS also has a global infrastructure that can help deliver applications to customers around the world. These features can help the company maintain performance and availability during periods of high traffic.

### Services:
- Amazon EC2 – Compute resources
- Elastic Load Balancing – Distributes traffic across servers
- Amazon EC2 Auto Scaling – Automatically adjusts computing capacity
- Amazon CloudFront – Global content delivery
- Amazon RDS – Database service


## Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | AWS offers a wide range of services and flexible options that can support a startup as it grows. |
| Enterprise Organization | AWS | AWS provides a large selection of services, strong security, and scalable infrastructure for enterprise workloads. |
| Microsoft Environment | Azure | Azure integrates closely with Microsoft products such as Windows Server, Microsoft 365, and Active Directory. |
| AI / Machine Learning | GCP | GCP provides strong AI and machine learning tools, including Vertex AI, as well as powerful computing resources. |
| Kubernetes Deployment | GCP | GCP provides Google Kubernetes Engine (GKE), a managed Kubernetes service designed for deploying and managing containerized applications. |
| Global Web Application | AWS | AWS provides global infrastructure, load balancing, automatic scaling, and content delivery services for highly available web applications. |
