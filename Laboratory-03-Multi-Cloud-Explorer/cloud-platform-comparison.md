## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers the broadest range of cloud services. It provides a large variety of services for computing, storage, databases, networking, security, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure best integrates with Microsoft technologies. It works especially well with Microsoft products such as Windows Server, Microsoft 365, Active Directory, and .NET, making it a good choice for organizations that already use Microsoft products.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud Platform is particularly strong in Artificial Intelligence and Kubernetes. Google Cloud provides AI tools such as Vertex AI and its managed Kubernetes service, Google Kubernetes Engine (GKE).

### 4. Which cloud platform would you personally choose and why?

I would personally choose Google Cloud Platform. I would choose it because of its strong artificial intelligence, data analytics, and Kubernetes capabilities, which are useful for developing modern applications.
