# Mission Reflection

## 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most was Google Cloud Platform (GCP). I was especially impressed by its strong Artificial Intelligence, Machine Learning, data analytics, and Kubernetes capabilities. GCP provides useful tools such as Vertex AI and Google Kubernetes Engine, which can support modern applications and research projects.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Azure, and GCP all provide similar core cloud services, including virtual machines, object storage, databases, networking, identity management, and Kubernetes. They all allow organizations to use computing resources through the cloud instead of maintaining all physical infrastructure themselves. However, each provider has different strengths, pricing options, and integrations.

## 3. How do business requirements influence cloud platform selection?

Business requirements are very important when selecting a cloud platform. Factors such as budget, existing technology, application type, performance, security, scalability, and geographic requirements can influence the decision. For example, a company using many Microsoft products may benefit from Azure, while an AI-focused company may prefer GCP.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

Acting as a Cloud Solutions Consultant taught me that there is no single cloud provider that is best for every organization. I learned how to analyze a client's requirements and match those requirements with appropriate cloud services. I also learned that understanding the client's existing technology and future goals is important when making a cloud recommendation.

## 5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?

My GitHub Cloud Computing Portfolio has improved because it now contains practical research, comparisons, recommendations, and Linux investigation results. I learned how to document cloud services using Markdown and organize technical information clearly. The portfolio now demonstrates not only my knowledge of AWS, Azure, and GCP, but also my ability to make cloud decisions based on real business requirements.
