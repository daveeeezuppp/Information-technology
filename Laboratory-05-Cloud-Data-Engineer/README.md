# Laboratory 05 – Cloud Data Engineer

## Mission Overview

This laboratory focused on deploying an object storage server using MinIO and Docker. It introduced the basic concepts of cloud storage, buckets, and containerized applications.

## Objectives

* Understand object storage and its uses.
* Deploy a MinIO storage server using Docker.
* Learn how to access the MinIO web console.
* Understand how buckets organize stored objects.
* Practice using Linux commands to manage containers.

## Tools Used

* **Linux Terminal** – Used to execute commands and manage files.
* **Docker** – Used to run the MinIO server in a container.
* **MinIO AIStor** – Used as the object storage server.
* **Web Browser** – Used to access the MinIO web console.

## Skills Learned

* Navigating directories using Linux commands.
* Deploying and managing Docker containers.
* Mapping container ports to host ports.
* Understanding Docker environment variables.
* Learning how buckets store and organize objects.
* Troubleshooting deployment errors and checking container logs.

## Conclusion

This laboratory helped me understand how object storage works and how Docker simplifies the deployment of storage services. I also improved my Linux command-line skills and learned the importance of organizing and protecting data in cloud storage systems.
